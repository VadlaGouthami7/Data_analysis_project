# Data_analysis_project
Data Analytics Project
# 📌 Project Overview
This project focuses on performing data cleaning, data analysis, and visualization using SQL, Microsoft Excel, and Power BI.

The objective was to transform raw data into meaningful insights by cleaning and preparing the dataset, analyzing it using SQL queries and Excel PivotTables, and creating interactive dashboards in Power BI.

### 🛠️ Tools & Technologies
Python - NumPy,Pandas for cleaning
SQL – Data querying, filtering, aggregation, and analysis
Microsoft Excel –  PivotTables, and exploratory analysis
Power BI – Data visualization and interactive dashboard creation

#### 🔍 Project Workflow
##### 1. Data Cleaning
Removed duplicate records
Handled missing and null values using pandas
Standardized data formats
Corrected inconsistent values
Prepared the dataset for analysis
##### 2. SQL Analysis
Performed SQL queries to extract and analyze relevant information from the dataset.

Key operations included:

Filtering data using WHERE
Aggregating data using SUM, COUNT, and AVG
Grouping data using GROUP BY
Sorting results using ORDER BY
Using conditional logic with CASE
Performing data analysis using different SQL queries
##### 3. Excel Analysis
Used Microsoft Excel for additional analysis and exploration.

Created PivotTables to summarize data
Analyzed trends and categories
Compared key metrics
Organized data for easier interpretation
##### 4. Power BI Dashboard
Created an interactive Power BI dashboard to present the analyzed data in a visually understandable format.

The dashboard includes:

KPI cards
Charts and graphs
Category-wise analysis
Trend analysis
Interactive filters and slicers
Summary views for quick insights
